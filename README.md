# healthcare-revenue-and-performance-analytics
Healthcare financial and operational analytics using Power BI, DAX, data modeling and SQL

## Project Overview 
A data analytics project focused on analyzing healthcare financial and operational performance 
to provide insights into revenue, collections, outstanding balances, departmental performance, 
profitability, budget performance, and potential revenue leakage

## Tools and Technologies

Microsoft Power BI
DAX
Data modeling
SQL

## Data Source

This project uses a structured healthcare management dataset containing hospital admissions, patient records, revenue transactions, payments, insurance claims, departmental costs, budgets, and revenue leakage information for analytical and reporting purposes.

## Disclaimer

This is a portfolio project developed to demonstrate data modeling, DAX calculations, interactive dashboard development, and healthcare financial analysis. The dataset and its underlying assumptions are intended for analytical demonstration and should not be interpreted as verified records or actual financial results from a real hospital.
